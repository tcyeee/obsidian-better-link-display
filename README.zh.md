# Better Link Display

[English](README.md)

一键把 Obsidian 笔记里干巴巴的网址，变成带网站名称和图标的漂亮书签。

**格式化前**

```
https://example.com
```

**格式化后**

> 🌐 Example Domain

它依然是一个普通链接，点一下照样打开网页。

## 安装

**从 Obsidian 内安装（推荐）**

1. 打开 **设置 → 第三方插件**，确认已关闭「安全模式 / 限制模式」。
2. 点 **浏览**，搜索 **Better Link Display**，点 **安装**。
3. 点 **启用**。

**手动安装**

1. 从 [Releases 页面](https://github.com/tcyeee/obsidian-better-link-display/releases) 下载 `main.js`、`manifest.json`、`styles.css` 三个文件。
2. 把它们放进 `<你的仓库>/.obsidian/plugins/better-link-display/` 文件夹（没有就新建一个）。
3. 重启 Obsidian，在 **设置 → 第三方插件** 里启用。

支持 Obsidian 1.0 及以上版本，电脑端和手机端都能用。

## 首次配置

插件自己没法读取网页标题，它会去问一个在线小服务 [Bookmarkify](https://bookmarkify.cc)。这个服务需要认得你，所以你需要先拿一个 **访问令牌**，只需配置一次。

1. 打开 [bookmarkify.cc](https://bookmarkify.cc)，登录后进入令牌管理页面。
2. 生成一个令牌并复制。
3. 回到 Obsidian，打开 **设置 → Better Link Display**，把令牌粘贴到 **访问令牌** 输入框。
4. 点 **测试**，显示「成功」就配置好了。

这个令牌是**只读**的：它只能用来查询网页的标题和图标，无法查看或修改你的书签和账号信息。

## 怎么用

### 用鼠标

在**编辑模式**下打开笔记，把鼠标移到一个网址上，链接上方会浮出一个 **格式化** 按钮。

下面这三种写法都支持：

```
https://example.com
[Example](https://example.com)
<https://example.com>
```

点击 **格式化**，链接会亮起呼吸般的高亮，插件正在查询网页信息，通常一两秒；查完之后，链接就变成带名称和图标的书签了。

如果查询失败，链接会闪一下红色，并弹出提示告诉你原因，**你的笔记不会被改动**。

### 用键盘（以及在手机上）

把光标放在链接里的任意位置，用命令面板（`Cmd/Ctrl + P`）执行 **格式化光标处的链接**，效果完全一样。手机和平板上没有鼠标悬停，就得用这个命令。

你也可以在 **设置 → 快捷键** 里给它配一个快捷键。

### 反悔了怎么办

把鼠标移到一个已经格式化过的链接上，会出现两个按钮：

- **重新格式化** —— 再查一次，刷新标题和图标（网站改名了就用它）。
- **重置** —— 把图标去掉，只留下最普通的 Markdown 链接：

  ```
  [Example Domain](https://example.com)
  ```

  重置是瞬间完成的，也不需要联网，它只是整理笔记里已有的文字。

  有一点需要预期：重置只会回到「标题 + 网址」，而不是你最初输入的样子。如果你一开始写的是光秃秃的 `https://example.com`，那段原文在第一次格式化时就已经被网站标题取代了，找不回来。

## 设置项说明

打开 **设置 → Better Link Display**。

| 设置项 | 作用 |
| --- | --- |
| **语言** | 在中文和 English 之间切换插件自己的设置界面与提示文案，默认跟随 Obsidian 的界面语言。 |
| **预览** | 一个实时的书签样例，方便你在应用下面两个选项之前先看看效果。 |
| **背景** | 给格式化后的链接加一层浅灰色圆角底色，像一张小卡片。默认关闭。 |
| **边框** | 给格式化后的链接加一圈浅灰色描边。默认关闭。 |
| **访问令牌** | 你访问查询服务的钥匙，旁边的 **测试** 按钮可以立即验证它是否可用。 |

背景和边框纯粹是外观设置，不会改动笔记内容，可以随意开关，开关后所有已格式化的链接会一起变。

> 一个小提示：**格式化光标处的链接** 这个命令的**名字**要重启 Obsidian 之后才会跟着语言切换，其余文案都是立即生效的。

## 遇到问题时

插件的所有提示都以「Better Link Display」开头，各条含义如下：

| 提示内容 | 该怎么办 |
| --- | --- |
| *请先在设置中填写访问令牌* | 你还没填令牌，见 [首次配置](#首次配置)。 |
| *访问令牌无效或已被吊销* | 去服务网站重新生成一个令牌，再粘贴进设置。 |
| *…… 无响应，请检查网络连接* | 你当前离线，或者服务暂时连不上，稍后再试。 |
| *…… 返回了错误* | 服务本身出了点状况，过一会儿再试。 |
| *服务无法读取该页面的标题* | 那个网站屏蔽了自动抓取，没什么可修的，标题只能自己写。 |
| *10 秒内没有响应* | 这次查询太慢了。笔记没有被改动，再点一次 **格式化** 即可。 |

**没有出现「格式化」按钮？** 先确认你在编辑模式（实时预览或源码模式）下——阅读视图里没有这个按钮。另外，代码块里、frontmatter 里的链接，以及 `![alt](……)` 这样的图片嵌入，都是有意跳过的。

**带括号的网址格式化不了。** 像 `https://en.wikipedia.org/wiki/Foo_(bar)` 这样的地址不会给出按钮，因为 Markdown 本身也判断不出这种网址在哪里结束。用尖括号包起来写成 `<https://en.wikipedia.org/wiki/Foo_(bar)>`，或者写成 `[文字](网址)`，就可以格式化了。

## 一些你可能想知道的事

**笔记始终是你自己的。** 插件写进笔记的是标准 Markdown，图标以文本形式存放在链接内部，不夹带任何插件私有标记。所以在下面这些情况下，你的书签照样正常显示：

- 禁用或卸载本插件；
- 把笔记复制到别的仓库、别的应用，或者一个纯 `.md` 文件里；
- 完全断网打开笔记。

**代价是：** 因为图标是以文本形式存下来的，源码模式下那一行会变得非常长，像一堆乱码。但在实时预览和阅读视图里，你看到的始终只是清爽的图标加标题。每个图标大约会给文件增加 1300 到 4800 个字符。图标统一按 48×48 保存，因此在高分屏上依然锐利，显示时则与正文字号齐平。

**不会有任何偷偷摸摸的动作。** 只要你不点 **格式化**、不执行命令，插件就不会联网；打开笔记不会发出任何请求。格式化一次刚好发两个请求：一个向查询服务要标题和图标地址，一个把图标下载下来。只下载 `https` 开头的安全地址，而且必须确实是图片才会使用。

## 开发者信息

服务接口约定见 [api.md](api.md)。

```bash
npm install
npm run dev      # 监听构建
npm run build    # 类型检查 + 生产构建
npm test         # 单元测试
```

构建产物是 `main.js`，它与 `manifest.json`、`styles.css` 一起被 Obsidian 加载。
